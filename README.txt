HONEY HOME — เว็บไซต์ร้านน้ำผึ้งตัวอย่าง

ไฟล์หลัก: index.html

วิธีเปิดดู:
1. ดาวน์โหลดและแตกไฟล์ ZIP
2. เปิดไฟล์ index.html ด้วย Chrome, Edge หรือ Safari
3. เว็บไซต์จะแสดงหน้าแรก สินค้า 2 SKU และตะกร้าสินค้า

สิ่งที่ทำได้:
- แสดงสินค้า HN-001 และ HN-002 พร้อมราคา
- เพิ่มสินค้าเข้าตะกร้า
- เพิ่ม/ลดจำนวนสินค้าและคำนวณยอดรวม
- กรอกข้อมูลผู้รับเพื่อทดลองยืนยันคำสั่งซื้อ

ข้อจำกัด:
- เป็นเว็บไซต์หน้า Front-end สำหรับต้นแบบงานเรียน
- ยังไม่เชื่อม Google Sheets, ระบบชำระเงิน, GitHub หรือ Vercel
- การยืนยันคำสั่งซื้อเป็นการสาธิตในหน้าเว็บ ไม่ได้บันทึกหรือส่งออเดอร์จริง

การนำขึ้น GitHub/Vercel:
อัปโหลด index.html ไปยัง GitHub repository แล้วเลือก Import Project ใน Vercel
โดยใช้ค่าเริ่มต้นสำหรับ Static Site ได้
